# Examples

Every "bad" line below was live on prietoteran.com. They are kept here as a record of what going too far looks like, so it does not happen again.

The pattern behind all of them: a task said "replace the free consultation with a paid audit", and the price ended up in the title tag, the hero badge, the subtitle, three buttons, a step title, the contact paragraph and the form footnote. Paid is the business model. It was never meant to be the brand.

---

## Title tag

**Bad**

```
Automation Audit Switzerland | 90 Minutes, 450 EUR | Osmel Prieto Teran
```

The first thing a search result showed was a price for a meeting with a stranger.

**Good**

```
Salesforce & ERP Automation Switzerland | Osmel Prieto Teran
```

The title is about the work. The price is a detail of the engagement, discovered later, on the page.

---

## Meta description

**Bad**

```
Paid 90-minute automation audit for Swiss B2B teams: 450 EUR, written
one-pager naming your bottleneck and what to automate first. Salesforce,
ERP and API work. Remote, CET.
```

**Good**

```
Salesforce and the ERP hold the same order and neither is trusted. I find
where the process breaks and build the fix. Independent engineer, Bern.
```

Recognition, then what I do. No number.

## Hero badge

**Bad**

```
Paid 90-minute audit · 450 EUR · Written one-pager
```

A price tag under the H1, before the reader knows who is talking.

**Good**

```
Bern · Salesforce · ERP
```

Location and craft. It tells a Swiss reader everything they need in three words.

---

## Hero subtitle

**Bad**

```
Describe what's slow or manual. In a paid 90-minute audit I name the
bottleneck and tell you what to automate first.
```

The reader has to accept a paid engagement before the second sentence is over.

**Good**

```
Your team re-enters the same order in two systems, approvals sit in an
inbox for days, and nobody can say where the time goes. I find the
bottleneck and build the fix.
```

Their situation first, in their nouns. Then what I do. The audit is not mentioned yet, because nothing has been earned yet.

## Primary CTA

**Bad**

```
Request the paid audit
```

**Good**

```
Tell me what's stuck
```

A conversation verb. The button asks for a sentence, not a purchase order.

## How-it-works steps

**Bad**

```
1. Paid audit, 90 min      450 EUR. Process, systems, volume.
2. Written one-pager       Bottleneck and what to automate first.
3. Optional 4-day sprint   2,800 EUR fixed. Build and handover.
```

Two of the three steps are prices. This is a price list, not a path.

**Good**

```
1. Conversation, 90 minutes   The process, the systems, the volume behind it.
2. Written one-pager          Where the bottleneck is and what to automate
                              first. Yours to keep.
3. Optional build             A four-day sprint or longer freelance work,
                              if it makes sense.
```

The path is legible. Duration stays because it respects their calendar. The numbers move to the offer block.

## Offer block

This is the one place where money is discussed, so it is the one place where the price belongs. The old version was still shouting inside it.

**Bad**

```
90-minute automation audit, 450 EUR
- 90 minutes with the engineer who would build it
- A written one-pager: your bottleneck and what to automate first
- Fixed price, no free discovery call
[ Request the paid audit ]
```

"Fixed price, no free discovery call" argues with an objection the reader had not raised. "Request the paid audit" repeats the price in the button.

**Good**

```
The 90-minute audit
- 90 minutes with the engineer who would do the work
- A written one-pager: where the bottleneck is and what to automate first
- 450 EUR, fixed
[ Start a conversation ]
```

The price is a bullet, stated once, at the same volume as everything else.

## Contact paragraph

**Bad**

```
Tell me what's slow or manual and which systems are involved. I reply with
audit slots and an invoice for the 450 EUR.
```

The word "invoice" appears before the reader has written a single line.

**Good**

```
Tell me what's slow or manual and which systems are involved. I read it and
reply with a few times that could work.
```

## Form helper text

**Bad**

```
The audit is 450 EUR. I reply with available slots and an invoice. No spam.
```

**Good**

```
I read every message myself. No newsletter, no spam.
```

A form footnote reassures. It does not re-sell.

## German

German is where restraint is easiest to lose, because the literal translation of a pushy English line sounds even pushier.

**Bad**

```
Bezahltes 90-Minuten-Audit · 450 EUR · Schriftlicher One-Pager
Bezahltes Audit anfragen
Fixpreis, kein kostenloses Erstgespräch
Jetzt buchen
```

`Bezahltes`, `Fixpreis` and `Jetzt buchen` together read like a promotion. The line about no free first meeting is defensive: it answers a question nobody asked.

**Good**

```
Bern · Salesforce · ERP
Sagen Sie mir, wo es klemmt
450 EUR, fix
Gespräch starten
```

`Sie`, plain nouns, no `Jetzt`, no `gratis`. A Swiss COO would click it.

## Slogans that could belong to anyone

**Bad**

```
Problem-solver. From boardroom requirement to working code.
Full Ownership
Bridge Builder
```

Any consultant could paste these onto their own homepage without changing a word.

**Good**

```
From the requirement in the meeting to the code that runs it.
You keep the code
Systems experience
```

Still short, but specific enough that it could only be about this work.
